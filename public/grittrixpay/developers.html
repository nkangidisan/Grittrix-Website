Quick Start

01. Install SDK

npm install @grittrix/pay-sdk

02. Initialize

import GrittrixPay from '@grittrix/pay-sdk'; const pay = new GrittrixPay({ apiKey: process.env.GRITTRIX_API_KEY, environment: 'production' });

03. Create a Payment

const payment = await pay.createPayment({ amount: 120000, currency: 'UGX', phone: '+256772XXXXXX', network: 'auto', webhookUrl: 'https://yourapp.com/webhook' });

  • phone * string
  • description string

Response
