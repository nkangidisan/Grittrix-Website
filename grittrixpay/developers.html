🛠️ Developer API

Built for developers who hate complexity.

3 endpoints. Auto-routing. Full STK push control.

● API Status: Operational

Quick Start

1. Create Payment

POST /create-payment
{
  "amount": 50000,
  "currency": "UGX",
  "business_id": "biz_123"
}

Returns: { "payment_link": "pay.grittrix.com/abc123" }

2. Trigger STK Push

POST /pay
{
  "payment_id": "pay_8f3k",
  "phone": "+256772XXXXXX"
}

3. Handle Webhook

{
  "event": "payment.confirmed",
  "amount": 50000,
  "phone": "+256772XXXXXX"
}
